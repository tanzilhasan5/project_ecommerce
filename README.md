# Storly – Multipurpose eCommerce Tailwind CSS Web Application

A modern, high-performance eCommerce template inspired directly by **Storly – Multipurpose eCommerce Tailwind CSS Template**.

## 🌟 Features Included

- **Header & Navigation**:
  - Multi-currency switcher (USD `$`, BDT `৳`, EUR `€`) with instant real-time price updates.
  - Live Omnibar search bar with instantaneous autocomplete suggestions and product previews.
  - Category mega dropdown menu & mobile responsive navigation.
  - Wishlist counter, Cart item counter & subtotal live tracker.
- **Hero Showcase**:
  - Interactive hero banner carousel with auto-rotation, slide indicators, and manual controls.
  - Category quick links & stacked promotional cards for tech gadgets and farm-fresh organics.
- **Value Badges**:
  - Free express delivery tracker, 30-day money back guarantee, 24/7 priority support, and encrypted payments.
- **Category Grid**:
  - Multi-category pills/circles (Groceries, Electronics, Fashion, Home & Living, Beauty).
- **Flash Deals of the Day**:
  - Live animated countdown timer (Hours : Minutes : Seconds).
  - Stock remaining progress bars ("Sold: 88 / Stock: 45").
- **Product Catalog & Filters**:
  - Filter by category tab with zero page reloads.
  - Hover action overlay (Quick View eye, Wishlist heart).
  - Formatted ratings, badges (*Organic, Flash Deal, Trending, Best Seller*).
- **Slide-out Cart Drawer**:
  - Live quantity adjustment, item removal, free shipping progress bar (threshold $50).
  - Coupon system (enter `STORLY15` for 15% discount or `WELCOME` for 10% discount).
  - Real-time subtotal, discount, shipping, and total calculations.
  - `localStorage` persistence so cart items remain even on refresh.
- **Quick View Modal**:
  - High-res product images with thumbnail gallery selector.
  - Stock availability, SKU, star ratings, variant selection (size, colors), and quantity counter.
- **Wishlist System**:
  - Bookmark items with 1-click "Move to Cart".
- **Complete Checkout Flow**:
  - Customer contact details & delivery address form.
  - Payment method options (Cash on Delivery, bKash / Nagad Mobile Banking, Credit Card).
  - Order confirmation screen with unique order tracking ID and invoice details.
